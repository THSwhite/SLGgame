# 遊戲設計文件（GDD）

> 這是一份會持續更新的文件。✅ 表示已實作，🕒 表示已規劃。

## 1. 概念
即時制（可暫停、可加速）的 2D 國戰策略遊戲，結合經營、資源控制與多方競爭。
參考：鋼鐵雄心 4（國策、外交、戰爭）、WorldBox（地圖上的國家自然發展）。

- 先做 **單人對 AI**，之後做 **多人連線**（架構從一開始就支援）。
- 地圖：六角格（pointy-top，odd-r 座標）。

## 2. 核心循環
人口 → 勞力 → 資源 → 建築／國土 → 更多人口；擴張後與其他國家接觸 → 外交或戰爭。

## 3. 開局 ✅
- 隨機地圖（目前用固定種子的測試地圖）。玩家只看得到 **陸地與海洋**，看不到地形細節與資源。
- 選擇一塊陸地作為起點 → 建立 **營地**（起始的國土建築），並獲得 3 位 LV1 村民。
- 營地周圍 2 格自動成為「已探索」與國土。
- 各國起點之間至少相距 10 格。

## 4. 地圖與迷霧 ✅
三層資訊：
| 層級 | 看得到什麼 |
|---|---|
| 未探索 | 只知道是陸地或水域 |
| 已探索 | 地形與資源（可能是舊資訊） |
| 視野內 | 即時狀態，包括其他國家的單位 |

- **國土範圍內一律在視野內。**
- 村民本身有 1 格視野，營地有 3 格視野。

### 地形（`src/sim/data/terrain.json`）
| 地形 | 可耕作 | 移動耗費 | 可能的資源 |
|---|---|---|---|
| 草地 | ✔ | 1 | 糧食 |
| 泥地 | ✔ | 1.6 | 糧食（少） |
| 森林 | ✘ | 1.5 | 木材、糧食 |
| 石地 | ✘ | 1.3 | 石材、礦石 |
| 沙地 | ✘ | 1.2 | 石材（極少） |
| 海洋 / 湖泊 | — | 不可通行 | 湖泊是淡水，可為周圍農田提供加成 🕒 |

## 5. 村民 ✅（部分）
- 指令：**探索**（花 5 秒解鎖一塊地，得知資源）、**採集**（採集該地的資源）、**移動**、**停止**。
- M1 簡化：採集到的資源直接進入國庫，不用搬運回營地。
- 狀態：閒置、移動、探索、採集；🕒 建造、訓練、駐守。

## 6. 人口與糧食
- ✅ 每位村民固定消耗糧食（LV1：1 糧／分；LV2：1.5 糧／分）。
- ✅ 糧食歸零時，所有工作效率 ×0.5。
- 🕒 **管理選單**（每位玩家都有）：設定人口生產速度（n 秒／人），人口上限由民宅數量決定。
- 🕒 設計原則：**非戰時期，正常發展下糧食一定持平或成長。** 糧食淨值為負時，自動暫停人口生產。
- 🕒 人口等級：
  - LV1：不可從軍。
  - LV2：仍是村民，但可以從軍；身體素質較好，所有工作效率 ×1.3；糧耗較高。
- 🕒 **戰爭懲罰**：戰時，被設定為士兵的人口，糧耗比非戰時同等級的士兵更高（×1.25）。

## 7. 建築 🕒
| 建築 | 條件 | 效果 | 國土建築 |
|---|---|---|---|
| 營地 ✅ | 開局建立 | 國土半徑 2、視野 3 | ✔ |
| 農田 | 草地、泥地等可耕作地 | 產出糧食；周圍有淡水時有加成 | |
| 礦場 | 任何陸地 | 石地產量正常，非石地產量極少 | |
| 民宅 | 國土內 | 提高人口上限 | ✔ |
| 兵營 | 國土內 | 村民入營 n 秒後升級，訓練期間不能做其他事 | ✔ |
| 瞭望塔 | 國土內或國土邊緣 | 有士兵駐守時，才提供視野與國土；國土範圍最大 | ✔（需駐軍） |
| 研究所 | 國土內 | 研究科技樹與國策 | |

### 國土規則
- 國土建築使周圍一定格數成為國土（只包含陸地）。
- 🕒 **國土範圍必須互相連接**：新的國土建築只能蓋在能讓國土相連的位置。
- 🕒 有駐軍的瞭望塔擁有最大的國土範圍；撤兵或被攻佔後，國土會縮回。
- 🕒 非國土建築可以蓋在國土外一定距離內。附近沒有瞭望塔時，這些地方只是「已探索」狀態。
- 🕒 **忠誠度**：在國土外、附近又沒有駐軍瞭望塔的村民，忠誠度會逐漸下降，可能被策反或獨立。

## 8. 研究 🕒
- **科技樹**：可以累積，例如各種資源的採集效率、解鎖建築。
- **國策**：互斥的選擇，例如「以戰養戰」vs「養精蓄銳」；軍事路線「輕型」「重型」「游擊」；外交能力。

## 9. 外交 🕒
狀態機：未接觸 → 已接觸 → 建交中 → 正式邦交 ／ 宣戰 → 冷卻期
- 不能直接攻擊其他國家，必須先**宣戰**（之後可加入動員期）。
- 建交後，雙方都要在期限內建立對方的**領事館**，否則邦交破裂，並進入一段不能再次建交的冷卻期。
- 邦交帶來貿易與交流（例如共享視野、研究加成）。

## 10. 戰鬥 🕒
先用自動結算：同一格內的敵對部隊，依攻擊、防禦與地形加成，每秒互相傷害。

## 11. 勝利條件 🕒
征服、國土佔全地圖一定比例，或撐過指定時間且國力第一（待定）。
